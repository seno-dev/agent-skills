# 画面の見せ方を直す

指定された画面の、ユーザーに見える文言、情報やボタンの順・配置、見出し、補足など、見た目だけを直す。ほかの変更とはコミットを分ける。

作業は gemini 3.8 flash medium のサブエージェントに出す。

## 直し方

以下を満たし、本番でユーザーに見せられる高品質なものにする。すでに条件を満たしている箇所はそのままでよい。

- 内部用語、メタ情報、本番用でない文を含まない。
- 文言・表現を日本語として違和感のない自然なものにする。
- わかりやすい配置にする。
- 主情報と補足を分け、同じ強さの文を並べない。
- 初見で誤解なく読めるようにする。

情報が抜け落ちないようにする。表示の内容はわかりやすくしてよいが、どの状態で何を出すかという条件分岐は変えない。計算、保存、API、状態遷移も変えない。

## 終わり方

- 変えた文言を、画面ごとに変更前と変更後の一覧にして報告する。
- 文言を変えて既存のテストが壊れたら、テストの文字列を合わせて直し、通ることを確かめる。

## 含めないこと

- ブラウザでの確認
- リポジトリの `verify-*` スキル
- e2e の新しい実装と実行
