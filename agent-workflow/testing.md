# テスト

- 計算や状態遷移の規則は単体テストで確認する。
- 状態によって画面に出る内容は e2e で確認する。状態ごとのデータを用意し、外部サービスはモックする。
- ブラウザでの確認は、ユーザーが頼んだときだけ行う。手順は verify-screen コマンドに従う。
- 外部サービスとの接続を変えたときの実環境の確認は、ユーザーが手動で行う。

## リポジトリ固有

- 当該プロジェクトに `.cursor/skills/verify-screen/`（または同等の verify スキル）がある場合、ブラウザ確認の手順は **そちらの SKILL.md を Read して優先**する。無い場合は上記の一般方針のみに従う。
